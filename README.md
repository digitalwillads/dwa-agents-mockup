# DWA agents mockup

A clickable mockup of DWA's agents in Barbara: the DWA agent, each section agent under it, and the verifiers that check their work. It is one static page, `index.html`, served by GitHub Pages.

The future dates, and the cases marked Example, are examples. Nothing on the page sends anything.

To publish a new build: `./publish.sh [path to the built page]` (default: `~/Desktop/business-projects-mockup.html`).
